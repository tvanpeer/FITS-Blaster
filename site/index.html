Cull a night's frames at full speed: thumbnails, the frame, its measurements and FITS headers in one window.

What it does

  • Measures star quality — FWHM, eccentricity, SNR, star count, PSF Signal Weight, and sky background — directly from raw pixel data
  • GPU-accelerated rendering of 16 MP+ FITS files with no perceptible lag
  • Session chart with drag-to-select for fast batch culling
  • Filter-aware grouping: Ha, OIII, SII, RGB, and more
  • Auto-Flag with configurable thresholds
  • Subfolder scanning for multi-night sessions
  • Rejected frames go to a REJECTED folder, optionally renamed so PixInsight's WBPP skips them
  • Export the frame list with metrics and FITS header values as CSV, TSV or a text report
  • Works fully offline — only a lightweight daily update check uses the network
